# Introduction

This is a sample blog post that demonstrates the expected structure and format for blog content in this project.

## Getting Started

To add your own blog posts, create a new `.md` file in the `content/blog/` directory following this structure.

## Key Points

- Frontmatter fields are required: `title`, `date`, `excerpt`, `publish`, and `tags`
- The `date` field should be in `YYYY-MM-DD` format
- Set `publish: true` to make the post visible on the site
- Use markdown for all content formatting
